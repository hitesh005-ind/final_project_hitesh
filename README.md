# final_project_hitesh
🌍 Air Quality Data Analysis Using Python
📊 An Exploratory Data Analysis Project
Welcome to my Air Quality Data Analysis project! 🚀
This project focuses on analyzing the AirQualityUCI dataset using Python. The project includes data cleaning, preprocessing, statistical analysis, and visualization to understand air-quality patterns and relationships between different environmental factors.
🎯 Project Objectives
The main objectives of this project are:
🧹 Clean and preprocess the air-quality dataset
📅 Process and combine Date & Time information
❌ Handle missing and invalid sensor values
📊 Perform statistical analysis
📈 Analyze CO concentration over time
🌡️ Analyze temperature over time
💧 Analyze relative humidity over time
🔎 Understand the relationship between Temperature and CO
📦 Analyze the distribution of CO concentration
🔥 Study correlations between numerical variables
💾 Generate a cleaned dataset
🛠️ Technologies Used
🐍 Python — Main programming language
🐼 Pandas — Data cleaning and analysis
🔢 NumPy — Numerical operations
📊 Matplotlib — Data visualization
🎨 Seaborn — Statistical visualization
📁 OS — File and path handling






🧹 Data Cleaning
The dataset is cleaned and prepared before analysis.
The project performs:
✅ Removal of empty columns
✅ Cleaning of column names
✅ Conversion of numerical values
✅ Handling of decimal values
✅ Replacement of invalid -200 sensor values
✅ Missing-value analysis
✅ Duplicate removal
✅ Date & Time processing
✅ Sorting data according to time
📊 Visualizations
The project generates 7 different visualizations.
1️⃣ CO Distribution — Histogram 📊
Shows the distribution and frequency of CO concentration values.
2️⃣ CO Concentration Over Time — Line Graph 📈
Shows how CO concentration changes over time.
3️⃣ Temperature Over Time — Line Graph 🌡️
Shows changes in temperature during the recorded period.
4️⃣ Relative Humidity Over Time — Line Graph 💧
Shows changes in relative humidity over time.
5️⃣ Temperature vs CO — Scatter Plot 🔵
Shows the relationship between temperature and CO concentration.
6️⃣ CO Concentration — Box Plot 📦
Shows the distribution of CO values and helps identify possible outliers.
7️⃣ Air Quality Correlation — Heatmap 🔥
Shows the correlation between different numerical air-quality parameters.
